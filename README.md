# 🖋️ Unterschrift Üben - Signature Practice

Eine interaktive Website zum Erstellen und Üben verschiedener Unterschriftsstile.

## Features

✨ **Unterschriftsstile generieren**: Geben Sie Ihren Namen ein und sehen Sie 7 verschiedene Schriftarten
🎨 **Stilvorschau**: Verschiedene Kalligrafie-Stile (Elegant, Casual, Formal, Modern, etc.)
📝 **Übungsvorlagen**: Erstellen Sie druckbare Übungsblätter mit transparenten Vorlagen
📥 **Download-Funktion**: Laden Sie Ihre Übungsvorlage als PNG herunter
⚙️ **Anpassbare Optionen**: Hilfslinien und Zeilenanzahl einstellbar
📱 **Responsive Design**: Funktioniert auf Desktop und Mobilgeräten

## Verwendung

1. **Website öffnen**: Öffnen Sie `index.html` in Ihrem Browser
2. **Name eingeben**: Geben Sie den Namen ein, für den Sie Unterschriften üben möchten
3. **Stile ansehen**: Klicken Sie auf "Vorlagen Erstellen" um verschiedene Schriftarten zu sehen
4. **Stil auswählen**: Klicken Sie auf Ihren Lieblingsstil und dann auf "Stil auswählen"
5. **Üben**: Laden Sie die Übungsvorlage herunter und drucken Sie sie aus
6. **Trainieren**: Verwenden Sie die transparenten Vorlagen zum Nachzeichnen

## Technologie

- **HTML5**: Strukturierung der Webseite
- **CSS3**: Styling und Animationen
- **JavaScript**: Interaktive Funktionen
- **Canvas API**: Generierung der Übungsvorlagen
- **Google Fonts**: Verschiedene Kalligrafie-Schriftarten

## Installation

1. Laden Sie alle Dateien herunter
2. Öffnen Sie `index.html` in einem modernen Webbrowser
3. Internetverbindung erforderlich für Google Fonts
